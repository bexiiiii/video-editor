## 9. Secret sauce (beyond video 1)

1. **Face -> app portal**: a live hook with a title sticker, then a light-orb "portal" with a sub boom into the UI world, mirrored at the end. It feels like the creator "opens an app".
2. **Interactive UI grammar**: select, check, dim the others, toggle status, select text, type "…", count. Every scene has a tap-like state change, which simulates use, not slides.
3. **Step capsule + 110 px headline**: an iOS onboarding pattern ("1-qadam / Serial turi"), with the pager acting as screen progress.
4. **Apple 3D emoji as hero icons** inside pastel or glass squircles: premium with no illustration cost.
5. **Counting animations** (1->30, follower ticks) and **sequential grid fills** visualize the idea of time and series.
6. **Glassmorphism only on blue** (translucent tiles and unselected rows at 50 % white). Light and dark stay solid.
7. **Music only under the graphics**: the live parts stay intimate, while the UI section gets a pulse.

**What a naive recreation gets wrong**
- It makes the flash a simple white fade; it needs a travelling, growing orb with a bloom and a sub boom.
- It applies selection without dimming the alternatives.
- It moves the ✓ badge in with the selection instead of popping it about 0.8 s later.
- It counts linearly instead of easing out.
- It uses flat emoji or icon fonts instead of Apple 3D emoji.
- It uses the same dark gradient as video 1; this one has a directional light wedge and grain.
- It forgets that the pager also advances.
- It places the sticker without the overlapping 🍿 or uses a non-uppercase font.
